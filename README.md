# Language-Translation-System-NLP-Machine-Learning

## Project Overview

This project focuses on building a Machine Learning-based Language Detection System that identifies the language of a given text. It uses Natural Language Processing (NLP) techniques to preprocess text data, extract meaningful features, and classify text into its corresponding language.

## Objectives

- To identify the language of a given text automatically.
- To preprocess text data for Machine Learning.
- To apply text vectorization for feature extraction.
- To train a Naive Bayes classifier for language classification.

🛠️ **Technologies Used**

- Programming Language: Python
- Libraries: Pandas, NumPy, Scikit-learn
- Concepts: Natural Language Processing (NLP), Text Preprocessing, Text Vectorization, Machine Learning
- Environment: Jupyter Notebook

📊 **Dataset**

The dataset contains text samples along with their corresponding language labels. It is used to train and test the model for identifying different languages.

🔄 **Project overflow**

1. Data Loading: Load the language dataset using Pandas.
2. Text Preprocessing: Prepare the text data for model training.
3. Feature Extraction: Convert text into numerical features using text vectorization.
4. Model Training: Train a Naive Bayes classifier using the extracted features.
5. Language Prediction: Predict the language of given text samples.

🔄 **Machine Learning Algorithm**


Naive Bayes Classifier

Naive Bayes is a probabilistic Machine Learning algorithm used for classification tasks. In this project, it is applied to classify text samples based on their language-related features.
